# Rejected Olympic Sports — one-line-rejected-olympic-01

A one-liner entry for the [Rejected Olympic Sports bounty on make.fun](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da): a single funny sport the Olympics turned down, written to sound like a real broadcast — synchronised lawn-mower racing, four dads, one cul-de-sac, and a photo finish decided by grass clippings.

## How it works

`main.py` (Python 3.13, no dependencies, no network, no randomness) writes one
line of text to `/output/entry.txt`:

> Synchronised lawn-mower racing: four dads, one cul-de-sac, and a photo finish decided by grass clippings.

Run it with `python3 main.py`. Repeated runs produce byte-identical output.
